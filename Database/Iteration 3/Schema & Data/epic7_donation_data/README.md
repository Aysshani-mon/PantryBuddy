# Epic 7 – Food Donation Centre DataThis folder contains the static data prepared for **Epic 7 – Food Donation Centre**.The data supports food donation centre discovery and accepted-food matching in the PantryBuddy system.## Files1. `donation_centres.csv`: **27 donation centres**, mapped to `donation_centres`.2. `donation_centre_accepted_foods.csv`: **190 accepted food records**, mapped to `donation_centre_accepted_foods`.## Data RelationshipThe two datasets are linked through `centre_id`:`donation_centres.centre_id` → `donation_centre_accepted_foods.centre_id`The `category_id` in `donation_centre_accepted_foods.csv` references the existing product categories in the database.## Data VerificationDonation centre information and accepted food requirements were collected from available organisation websites and referenced sources.The `verification_source_url` in `donation_centres.csv` records the source used to verify each centre.Where specific accepted food items could not be confirmed, no accepted-food records were added to avoid unsupported assumptions.## Import Notes- CSV encoding: **UTF-8**- `centre_id` values should be preserved to maintain relationships between the two files.- Timestamps use MySQL `DATETIME` format: `YYYY-MM-DD HH:MM:SS`.- Empty optional fields should be imported as SQL `NULL`.
